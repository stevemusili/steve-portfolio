# Steve Portfolio

A responsive personal portfolio website showing testimonials, projects, and contact details.

## Live Demo Link



## Features

- Home section which includes a short introduction
- A list of testimonials rendered to the page using JavaScript
- Projects section rendered to the page using JavaScript
- Project cards displays project title, description, and technologies used
- Contact section with email and link to [GitHub](https://github.com/stevemusili)
- Hover effects on buttons, links, and project cards
